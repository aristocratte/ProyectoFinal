# HablaChido

Diccionario de bolsillo del español de la Ciudad de México, con fichas, audio, favoritos y quiz. Proyecto final de APLICACIONES MÓVILES, equipo GIGN (Universidad La Salle México).

La app está en [`hablachido/`](hablachido/). Instrucciones para ejecutarla en [`hablachido/README.md`](hablachido/README.md).
